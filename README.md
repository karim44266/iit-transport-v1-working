# IIT Transport
1. Supabase > SQL Editor: run supabase/schema.sql once.
2. Supabase > Authentication > Providers > Email: turn OFF "Confirm email" while testing.
3. Paste SUPABASE_URL and SUPABASE_ANON_KEY in js/config.js.
4. Run: python3 -m http.server 8000 -> http://localhost:8000
(js/store.local.js is the old offline demo layer, no longer loaded.)
