# 🚗 IIT Transport

A carpooling web app for **IIT students**, connecting students who have a car with students who need a ride to university.

🔗 **Live demo:** [https://karim44266.github.io/iit-transport-v1-working/]
<img width="1807" height="971" alt="image" src="https://github.com/user-attachments/assets/6c4bb6be-cb05-4883-8c6a-0ec5dc565aab" />

## The problem

Getting to IIT every day is hard for students without a car, while many drivers travel the same route with empty seats. IIT Transport brings them together in one place.

## How it works

**For drivers**
1. Open the app and tap **Offer a ride**
2. Choose the route from home to IIT by drawing your path on the map
3. Set the departure time and the number of available seats
4. Publish the ride

**For students looking for a ride**
1. Browse the rides offered by other students
2. Pick a ride and tap the map to choose where you want to be picked up
3. The driver receives a notification and can **accept** or **decline**
4. Once accepted, a **group chat** opens between the driver and the passenger to organize the details

## Features

- 🗺️ Interactive map to draw routes and select pickup points
- 🕒 Ride offers with time and available seats
- 🔔 Notifications for ride requests
- ✅ Accept / decline system for drivers
- 💬 Group chat opened automatically after acceptance
